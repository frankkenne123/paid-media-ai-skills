# Competitive Intelligence

Research what competitors are running, spot trending creative formats and offers, and build competitive intelligence reports that inform your own creative strategy.

---

## DATA SOURCES

### 1. Meta Ad Library (FREE) — Primary Tool
[facebook.com/ads/library](https://facebook.com/ads/library)

**What you can see:**
- All active Meta ads from any Page (public by law — Meta's transparency policy)
- Ad creative, copy, CTAs, landing URLs
- Ad run duration ("Started running on [date]")
- Platforms (Facebook, Instagram, Messenger, Audience Network)
- Regions the ad is shown in

**What you CANNOT see:**
- Spend, impressions, conversion data (confidential)

**How to use:**
- Search a competitor's Page name
- Filter: Active ads only, your country, platforms
- Download / screenshot creative for analysis

**Pro tip — longevity = winner:**
If an ad has been running for 60+ days, it's almost certainly profitable. They wouldn't keep paying to run it otherwise. These are the ads worth studying.

### 2. Google Ads Transparency Center
[adstransparency.google.com](https://adstransparency.google.com)

Lets you see Search, Shopping, Display, and YouTube ads from any advertiser. Less rich than Meta's tool but useful for Google-heavy competitors.

### 3. Foreplay (PAID — optional)
[foreplay.co](https://foreplay.co)

Best-in-class Meta ad library tool. Features:
- Save ads to "swipe files" organized by theme
- Track competitor new launches automatically
- Analyze ad longevity, format breakdowns
- Team collaboration on creative research

### 4. Semrush / SpyFu / SimilarWeb
For deeper keyword and traffic research (paid).

## COMPETITIVE RESEARCH WORKFLOW

### Step 1: Identify the Competitor Set (5–10 brands)

For a client, build a list of:
- **Direct competitors** (same product, same audience)
- **Aspirational brands** (bigger, where client wants to go)
- **Cross-category inspiration** (different product, same audience or same "vibe")

### Step 2: Scan Meta Ad Library for Each

For each competitor, document:
```
## [Competitor Name]

**Active ad count:** [number]
**Longest-running ad:** [started X days ago]
**Top 3 creative themes:** [what they emphasize]

### Top Active Ads (sorted by run duration):
1. [Screenshot/description] — Running 120 days — [Format: UGC video] — Hook: "[text]"
2. [Screenshot/description] — Running 90 days — [Format: Carousel] — Hook: "[text]"
3. [Screenshot/description] — Running 75 days — [Format: Static] — Hook: "[text]"

### Observations
- Primary offer: [discount / bundle / free shipping / etc.]
- CTA variety: [Shop Now, Learn More, Get Yours]
- Audience signals (based on ad copy): [age, pain points, motivators]
- Content types: [UGC X%, produced Y%, static Z%]
```

### Step 3: Identify Patterns Across Competitors

```
## Industry Patterns (from 10 competitors)

### Format Distribution
- UGC video: 55%
- Static image: 25%
- Carousel: 15%
- Produced video: 5%

### Hook Patterns (top 5 categories)
1. Problem-agitation ("Are you still dealing with [problem]?") — 40% of ads
2. Social proof ("Join 10,000+ customers...") — 20%
3. Before/after transformation — 15%
4. Discount-led ("20% off...") — 15%
5. Curiosity ("I didn't think this would work...") — 10%

### Offer Trends
- Free shipping threshold most common ($50-$75)
- BOGO less common than expected
- First-order discount (20%) is default

### Longest-Running Ads (likely most profitable)
- [Competitor A]: UGC unboxing — 200+ days active
- [Competitor B]: Customer testimonial carousel — 150+ days active
- [Competitor C]: Before/after weight loss — 120+ days active
```

### Step 4: Compare to Client's Current Creative

Build a gap analysis:
```
## Gap Analysis: [Client] vs Competitor Set

### What Competitors Do That [Client] Doesn't
- UGC video is 55% of competitor creative, but [Client] has 0 UGC video
- All competitors run before/after transformation ads; [Client] has none
- 8/10 competitors use a first-order discount; [Client] is full-price

### What [Client] Does That Competitors Don't
- Heavy producer video focus (expensive, low volume) — contrarian but likely hurting scale
- No social proof ads — missing table-stakes format

### Recommended Creative Queue (based on gap)
1. Launch UGC video ads (top format in category)
2. Test before/after transformation angle
3. Test first-order discount offer (risk: margin hit; reward: acquisition volume)
```

## MONITORING CADENCE

### Weekly (light)
- Check top 3 direct competitors for new ad launches
- Note any viral-looking creative (high volume of new ads in short time)

### Monthly (deep)
- Full scan of competitor set
- Document pattern shifts
- Update swipe file with new winning ads
- Recommend 2–3 creative tests based on findings

### Quarterly (strategic)
- Competitive landscape report for client
- Market positioning analysis
- Identify category evolution trends

## WHAT TO ACTUALLY DO WITH COMPETITIVE INTEL

**DO:**
- Identify trending formats and angles (social proof points toward validated customer psychology)
- Find gaps (things competitors aren't doing that could be differentiation)
- Steal the structure, not the execution ("UGC with a problem-agitation hook" — then write your own version)
- Notice longevity — 60+ day ads are winners; study why

**DON'T:**
- Directly copy competitor ad copy (legal risk + it's not actually differentiated)
- Chase every new competitor launch — many are tests that will be killed in 2 weeks
- Assume a competitor is "winning" because they're running a lot of ads (volume ≠ profit)
- Build a strategy entirely around what competitors do — they might be wrong

---

## LANDING PAGE / OFFER RECON

Don't just analyze ads — click through to their landing pages:
- What's the first headline on the landing page? (Ad-to-landing-page message match)
- What's the offer at checkout? (First order discount? Bundle?)
- Where's the social proof? (Reviews count, press logos, etc.)
- What's the sticky bar / exit intent popup saying?

This tells you what their full-funnel strategy is, not just the ad.

## NOTES
- Meta Ad Library data refreshes daily — set a weekly review cadence
- Save screenshots — competitors sometimes pause ads, and you lose the reference
- Track WHO made the creative (if visible in caption / @tag) — identifies UGC creators you could hire
- For clients with strong competitors, schedule quarterly competitive deep-dives as a recurring deliverable
