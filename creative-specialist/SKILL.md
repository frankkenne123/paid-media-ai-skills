## CREATIVE FATIGUE DETECTION

**Warning signals:**
- CTR dropping >25% week-over-week
- CPM rising >30% without audience size changes
- Frequency above 3.0 for the same audience

**Action thresholds:**
- Rotate creative when CTR drops >20% below peak
- New concepts every 7–14 days for high-spend campaigns (>$500/day)
- Monthly creative refresh for evergreen campaigns

---

## A/B TESTING METHODOLOGY

1. **One variable at a time** — hooks, formats, offers, CTAs (not all at once)
2. **Same audience** — control for audience differences across variants
3. **Statistical significance** — minimum 100 conversions or 1000 clicks per variant
4. **Minimum duration** — 7 days to account for day-of-week variance
5. **Document winners** — add to the creative playbook, retire losers

## PLATFORM-SPECIFIC SPECS

**Meta Ads:**
- Stories: 1080x1920px (9:16)
- Feed Posts: 1080x1080px (1:1)
- Link Ads: 1200x628px (1.91:1)
- Headline: ≤40 characters
- Primary Text: ≤125 characters (rest gets truncated)

**Google Ads:**
- Display: 728x90, 300x250, 160x600
- Search companion: 1200x628
- YouTube Thumbnail: 1280x720

**TikTok:**
- Video: 1080x1920 (9:16), 15–60 seconds
- Hook must land in first 2–3 seconds

## WEEKLY CREATIVE REVIEW

Every week, answer these five questions:

1. Which creative won this week? (scale it)
2. Which creative is fatiguing? (refresh it)
3. What do we need to create next week?
4. What are competitors running? (stay aware)
5. What's the next creative test?
